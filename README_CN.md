# ESP-APA

- [English](./README.md)

Espressif Audio Processing Algorithms（ESP-APA）是乐鑫为 ESP 系列 SoC 打造的端侧音频算法组件集合，聚焦 AI 语音交互、语音前处理、音频增强与智能音频应用需求。ESP-APA 采用模块化组件设计，各算法能力可按需集成，并提供标准化 API，帮助开发者在语音助手、智能音箱、会议终端、机器人及其他 AIoT 设备中快速构建可靠的音频处理能力。

## 组件

| 组件 | 说明 |
| :---: | :--- |
| [DOA](components/esp_apa_doa/README_CN.md) | 2/3/4 麦克风阵列声源到达方向（DOA）算法 |
| [哭声检测](components/esp_apa_cry_detection/README_CN.md) | 16 kHz 单声道 PCM 婴儿哭声检测 |
